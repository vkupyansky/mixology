# Mixology

Локальный редактор каталога вкусов. Показывает заполненность карточек и позволяет менять описание, теги, интенсивность, вкусовой профиль и ароматические ноты. В исходном каталоге 95 вкусов Darkside.

## Запуск

Нужны Node.js 24 LTS, pnpm 11.10.0 и PostgreSQL 16 или новее. Подготовьте отдельную БД и роль для этого проекта.

```sh
pnpm install --frozen-lockfile
node scripts/init-env.mjs
```

В созданном `.env` задайте единственный обязательный параметр `DATABASE_URL`: PostgreSQL URL вашей БД. Файл должен иметь права `0600`. Для удалённой БД настройте проверку TLS-сертификата через `sslmode=verify-full`.

```sh
pnpm db:setup
pnpm build
pnpm start
```

Откройте <http://127.0.0.1:3000>. Сервер слушает только loopback. Пользовательских аккаунтов нет; публичный доступ требует отдельной авторизации перед приложением.

`db:setup` создаёт отсутствующую таблицу и добавляет каталог из `data.json`. Повторный запуск сохраняет существующие карточки и внесённые правки. Команда не удаляет таблицы и данные.

Для разработки запустите `pnpm dev` и в отдельном терминале `pnpm dev:web`, затем откройте <http://127.0.0.1:5173>. Vite передаёт `/api` локальному backend; секреты в браузер не передаются.

## Данные

PostgreSQL хранит карточки. `data.json` содержит только исходные бренды, теги и описания вкусов. Секретов и пользовательских аккаунтов в каталоге нет. Рабочая БД и `.env` в Git не входят.

При сохранении поля блокируются до ответа сервера. Ошибка оставляет введённые значения в редакторе; успешное сохранение подтверждается только после ответа API. Одновременное редактирование одной карточки несколькими людьми не согласуется автоматически.

## Проверки

```sh
pnpm check
```

Команда выполняет форматирование, ESLint без предупреждений, строгую проверку типов, API-тесты, сборку, изолированную PostgreSQL-проверку и аудит зависимостей. Для проверки БД нужен Docker: временный контейнер запускается из закреплённого образа, удаляется после теста и не обращается к рабочим данным.

Отдельные команды: `pnpm test`, `pnpm test:db`, `pnpm build`. Текущее состояние и ограничения: [STATUS.md](STATUS.md).
