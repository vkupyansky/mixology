# Текущее состояние

Работают каталог, просмотр карточки и редактирование вкусовых характеристик. Восстановлены зависимости, сборка Vite, SQL-схема и повторяемый импорт 95 исходных вкусов. Пароли удалены из исходников; PostgreSQL настраивается через окружение.

Проверяются границы API, схема полей, строгие типы, сборка и зависимости. Изолированная проверка PostgreSQL покрывает повторный импорт в существующую таблицу без нового UNIQUE, сохранность правок и полный цикл GET/PUT/GET.

Приложение предназначено для локального редактора и не имеет пользовательской авторизации. Публичный сервер и прежняя рабочая БД не изменялись. Старые credentials необходимо заменить. Автоматического разрешения конфликтов при одновременном редактировании нет.
