# Mixology: правила разработки

- `frontend/src`: React-интерфейс; `backend`: Express API, конфигурация и SQL-схема.
- `shared/flavor.js`: общий контракт карточки; `scripts/setup-db.mjs`: повторяемый импорт каталога.
- Сохраняйте существующие карточки и правки. Не удаляйте таблицы, не создавайте дампы и не обращайтесь к рабочей БД в тестах.
- Единственная настройка подключения: обязательный `DATABASE_URL`. Секреты не включаются в Git, frontend, аргументы команд и логи; `.env` имеет права `0600`.
- Приложение локальное и без аккаунтов. Сохраняйте loopback и проверку Origin; доступ из сети требует отдельного решения об авторизации.
- Проверяйте API-ввод общим контрактом, используйте параметры SQL. Сохранение подтверждается ответом сервера; поля на время запроса блокируются.
- Зависимости закреплены в package.json и pnpm-lock.yaml. Установка: `pnpm install --frozen-lockfile`.
- Проверка: `pnpm check`. Предупреждения считаются ошибками; регрессии проверяются через реальный API и изолированный PostgreSQL.
- Обновляйте связанные README и STATUS. Перед публикацией проверяйте состав Git и запускайте Gitleaks с `--redact`.
